# Landing Page Danki Code

Projeto desenvolvido como prática de **HTML5** e **CSS3**, com foco em estruturação de páginas, estilização de formulários, organização de arquivos e responsividade básica.

> Projeto de estudo inspirado em uma landing page educacional.

## Tecnologias usadas

- HTML5
- CSS3

## Funcionalidades

- Cabeçalho com logo
- Seção inicial com chamada principal
- Lista de benefícios
- Formulário de contato/cadastro
- Seção descritiva do projeto
- Seção com planos/cards informativos
- Rodapé simples
- Layout responsivo para telas menores

## Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos como:

- estruturação semântica com HTML;
- uso de classes para organização do CSS;
- estilização de formulários;
- uso de imagens no projeto;
- criação de cards informativos;
- aplicação de `flexbox`;
- uso de media queries para responsividade;
- organização de pastas e arquivos.

## Como visualizar o projeto

Você pode abrir o arquivo `index.html` diretamente no navegador.
